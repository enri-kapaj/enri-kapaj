### 👋 About Me

I am a dedicated **Full-Stack JavaScript Developer** with a strong enthusiasm for **DevSecOps**, bringing hands-on experience in **Node.js**, **React**, and **TypeScript**. My passion lies in automation and building efficient, secure developer workflows.

My journey in software engineering began in early 2020, initially crafting websites with WordPress. Shortly thereafter, I transitioned into full-fledged development using JavaScript and its ecosystem. Since then, I have consistently worked with modern JavaScript technologies.

One of my recent and most exciting projects was building an **Internal Developer Portal**. It helped me learn more about DevOps principles, best practices, and automation. This project also strengthened my interest in platform engineering and tools that improve the developer experience.

I pride myself on being adaptable, a keen problem-solver, and deeply committed to continuous learning and delivering high-quality solutions.
